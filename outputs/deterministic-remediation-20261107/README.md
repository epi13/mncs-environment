# Deterministic remediation evidence

The consolidated accounting is `docs/DETERMINISTIC_REMEDIATION.md` in this
repository. `verification-receipt.json` binds tested source bytes, repository
revisions, commands and final outcomes. `manifest.json` hashes the retained
artifacts. Neither receipt converts generic process success into native Test
verification or measured agent usefulness.

- `cost-baseline.json`, `cost-native-stage1.json`, `cost-store-stage2.json`, and
  `cost-final.json`: complete raw wall samples, event/generation/logical-byte
  counts, native transport counters and process resource observations. Source
  bytes are pinned independently of the containing evidence commit.
- `entry-baseline.json` / `entry-final.json`: seven real-process unchanged-entry
  fixtures, including actual save/event counts and service-ready outcomes.
- `admission-baseline.json` / `admission-final.json`: matched scope prerequisites,
  explicit harness requests, and equal independently read provider state. Two
  advisory checks replace two unsuccessful invocation requests; live admission
  and the one actual provider execution remain.
- `profiles.json` and the matching raw `profile-*.pstats`: separate resident and
  fresh-handle cost attribution. `correlation-query-cost.json` measures the strict
  evidence/native projection query separately from request capture.
- `native-verification-durable/`: a real supported native Test operation with
  exact request, result, source/fingerprint/selection, immutable owner evidence,
  strict native joins and a completed ordinary Store-backed session. Its Store
  can be reopened with the existing Environment/Store APIs. Disposable filesystem
  caches were retired; referenced immutable Store bundles are preserved.
- `native-verification/`: the initial temporary-Store probe, retained only as
  historical evidence; use the durable proof above for current restart/readback.
- `logs/`: baseline, focused, primary-checkout and architectural proof outcomes,
  including the original four Doctor failures and the corrected consumer path
  assertion. Existing optional dependency skips remain explicit.

The cost and admission experiments are bounded mechanical fixtures. They do not
establish naturally occurring agent productivity, causal token savings, context
usefulness, a complete need denominator, or a learned-model utility cohort.
